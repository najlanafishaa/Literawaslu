Responsive Web Design

Teknik dan pendekatan modern untuk memastikan tampilan web optimal di berbagai ukuran layar, mulai dari smartphone hingga desktop monitor.

⚡ 1. Media Query

Media Query adalah salah satu teknik utama dalam CSS yang memungkinkan developer menerapkan style berbeda berdasarkan ukuran viewport atau lebar layar perangkat.

@media (max-width: 768px) {
  .product {
    flex-direction: column;
  }
}

💡 Penjelasan: Saat lebar layar berada di bawah 768 piksel, susunan elemen produk yang sebelumnya menyamping (horizontal) akan otomatis berubah menjadi vertikal (stacked).

Kombinasi Teknik Responsive Web Design

Responsive Web Design bukan cuma soal Media Query. Developer biasanya menggabungkan beberapa teknik pendukung berikut untuk menciptakan pengalaman pengguna yang fleksibel dan responsif:

📐 Flexible Layout

Menggunakan Flexbox atau CSS Grid agar susunan elemen dapat beradaptasi dan menyesuaikan ruang layar yang tersedia secara alami.

display: flex;
flex-wrap: wrap;

📏 Relative Units

Menggunakan satuan relatif seperti %, rem, atau vw daripada ukuran tetap (fixed px) agar skala teks dan komponen menyesuaikan layar.

width: 100%;
font-size: 1.2rem;

🖼️ Responsive Images

Memastikan gambar tidak meluap (overflow) melewati lebar layar serta memuat ukuran gambar yang efisien sesuai dengan perangkat pengguna.

max-width: 100%;
height: auto;

📱 Mobile-first Design

Pendekatan merancang tampilan dan tata letak untuk layar kecil (smartphone) terlebih dahulu, kemudian mengembangkannya secara bertahap (progressive enhancement) untuk layar yang lebih besar seperti tablet dan desktop.
